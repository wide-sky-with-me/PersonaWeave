# 场景预设只陈述参数，识别阈值不是遮挡保护

状态：有效
日期：2026-10-04

## 背景

换脸控制面板的四个场景预设原本用效果性文案：“强化五官清晰度”“减少侧脸与暗光生硬边界”“预防眼镜、饰品与发丝穿模贴图”。核对后发现这些说法没有实测依据，其中“遮挡防护”预设只是把 `similarity_threshold` 调到 0.42，而这个参数在 API 里是“用于目标人脸识别的余弦阈值”：眼镜和遮挡保护来自 XSeg 与 BiSeNet 掩码，始终开启，与阈值无关。同时，默认参数（auto、0.9、0.35、boundary）不匹配任何预设，新用户什么都没动，界面就显示“自定义微调”和“已微调”。

## 决策

- 预设文案只陈述参数，并说明真实含义：识别阈值决定哪些脸会被识别并替换，阈值越高越严格、跳过越多；眼镜与遮挡保护在所有预设下始终开启。“遮挡防护”改名为“严格匹配”。
- 推荐默认值（`RECOMMENDED_DEFAULTS`）是重置按钮和“当前状态”判断的唯一来源；参数等于默认值时显示“推荐默认”，只有偏离所有预设和默认值才显示“自定义微调”“已微调”。
- 套用预设不改研究许可模型的开关；只有用户在模型下拉里显式选 HyperSwap 才会打开 `allow_research_models`。

## 被放弃的方案

- **保留效果性文案并加“实验性”标签**：仍把未测量的说法当成产品承诺，违反“未经实测的数据不得伪装”的规则。
- **用阈值实现“遮挡防护”**：阈值调高只会让更多脸因 `identity_match_below_threshold` 被跳过，并不保护任何像素。
- **让预设 `portrait` 的强度等于默认 0.9 以消除“自定义微调”**：会让两个预设无法区分；改为单独识别推荐默认值。
- **在预设里自动开启 HyperSwap 与研究许可**：HyperSwap 为 ResearchRAIL，不随便携包分发，只能是用户的显式选择（见 [默认模型与许可](../swap/20261003-default-swap-model-and-licence.md)）。
