# 同网段访问追加显式 LAN 监听，保留尾网入口

状态：有效
日期：2026-10-14
范围：Mac Colima 原生 ARM64 CPU 部署的宿主端口发布。

## 背景

用户要求检查同一 WiFi 的实际访问。运行实例只发布尾网地址，LAN 端口连接失败；客户端和 Mac 有同网段路由，LAN SSH 握手可达。生成的 Lima 规则包含两种地址，缺口位于 Compose 发布而不是人物识别。

## 决策

通过可选 [LAN 覆盖文件](../../../docker-compose.lan.yml) 追加第二个显式地址，不替换原发布端口。LAN 地址必须显式配置；远端保存 COMPOSE_FILE，普通 Compose 调用也保留 CPU 和 LAN 覆盖。复用现有镜像与持久目录，在推理空闲时重建容器。部署方式只在 [操作指南](../../../docs/docker-deployment.md) 维护。

## 被放弃的方案

只替换尾网绑定会让异地入口消失；全接口绑定扩大会随其他接口启用而开放的范围。另起 SSH 转发和 LaunchAgent 会增加第二套端口生命周期。本次采用 Docker 已有发布机制，没有配置路由器或修改 Clash 订阅。

## 影响与验证

LAN IP 是 DHCP 地址，不保证跨 WiFi 或租约改变后继续有效；维护时更新变量、核对 Lima 转发并重建容器。路由器可保留该设备租约。本次没有再次重启 Mac。回归见 [容器测试](../../../tests/test_container_requirements.py)，真实直连网页、换脸及恢复见 [验收记录](../../../docs/validation/20261014-lan-access.md)。浏览器验收显式关闭系统代理并核对 TCP 对端，避免把代理访问误判为局域网直达。
