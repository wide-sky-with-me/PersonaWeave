# 2026-09-23 中国人物素材实测

当前素材的制作方向是用户确认的“自然上镜”：清秀、阳光、五官协调，保留真实皮肤质感。
人物均为内置 AI 生图服务创作的虚构中国年轻人；中国背景和年龄是创作设定，不是从图片推断的真实身份信息。
素材库生产契约见 [人像素材库](portrait-library.md)。

本批使用新人物编号 F45–F76、M45–M76，男女各 32 位，每人 16 张独立参考图，
覆盖左右转头、俯仰和微笑、大笑、惊讶、严肃等表情。原始图板、最终提示词、裁切图和
逐图检测报告保存在 `data/portrait_chinese_20260923/`；其中 `prompts.json` 为最终提示词，
`overrides/` 保存定向补图及提示词。制作方式为内置生图工具，自动裁切已获用户授权。

最初两个人物的未成年设定被服务拒绝，随后改为明确的 18 岁成年人；尚未生成的
16–17 岁设定也改为 18 岁。已成功生成的创作年龄未被重标。最终创作年龄均在用户要求的
16–25 岁范围内。年龄标签不能用于验证真实人的年龄。

复核命令：

```bash
uv run python -m scripts.prepare_portrait_refresh --root data/portrait_chinese_20260923
uv run pytest tests/test_portrait_library.py tests/test_documentation_consistency.py
```

检测使用本地 SCRFD 和 ArcFace。每张参考要求恰好一张人脸，人脸宽高至少 80 像素，
与同人物正脸相似度至少 0.35；每人左右主侧脸分别要求五点 yaw ≤ -0.65 和 ≥ 0.65。
角度名称是创作目标，五点 yaw 是归一化几何指标，不是精确角度测量；接近纯侧面的
小尺寸裁切可能使关键点方向不稳定，因此对不合格参考定向补做高清图并复测。
这些检查不能保证遮挡、小脸或极端姿态下的实际换脸质量。

现有安装更新只归档被替换的旧人物，保留原始素材、缩略图和 ID 供工程与历史引用，
不静默替换旧工程选中的人物。新建传输包只包含新版可选素材，以控制体积；
迁移已有工程时必须同时保留其完整旧素材库，不能直接用新包的 `data` 目录覆盖旧工程。
导入复用 `api/portraits/importer.py` 的 manifest 幂等导入，并检查旧资产记录和文件完整性。

本轮付费调用用于素材生成，未重新调用应用的付费精修接口。
