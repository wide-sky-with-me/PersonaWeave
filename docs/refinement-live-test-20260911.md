# 五人合影 AI 精修实测（2026-09-11）

本次使用用户明确授权的照片和已配置付费服务，通过真实浏览器完成本地换脸、分析、确认、补充意见及两轮生成。版本链和人工意见合并验证通过；两张候选的画质均不建议定稿，未执行接受或发布。这是一个样本的结果，不代表其他照片或模型配置的表现。

## 输入与运行边界

- 原图：`outputs/browser-real-swap/20260910-202940/4/original.jpg`，3656 × 5484，五人合影。
- 参考：`data/test_target/01.png`；只替换 P4（右起第二位、牛仔套装和眼镜），其余人物无身份参考。
- 冻结原图检测位置绑定 P4，候选不重新排序或重新绑定人物。本地重跑检测五张脸、替换一张脸，初稿与此前本地结果解码像素一致。
- 主会话：`0504fafbf9e54baa95f632950a76364b`，标题“五人合影精修验证.jpg”。证据目录：`outputs/browser-refinement-real/20260911-fixed/`。
- 生图通过项目 AIGateway，公开元数据记录别名 `personaweave-refine-default`、provider `litellm`、返回模型名 `gpt-image-2.5-flare`。返回名称不作为厂商身份或能力认证。
- 两次图像编辑均为单张当前完整 PNG 加文字，未附加原图、参考、裁剪或 mask。当前策略 `size: auto`，两次原生输出均为 **1024 × 1536**，随后整图规范化至 **3656 × 5484**。此观察不代表该模型的最大分辨率；适配放大不恢复原有细节。
- 每轮只生成一张；无自动重发、自动接受或局部回填。实际计费金额未获取，不按模型名称估算费用。

## 两轮过程与结果

| 步骤 | 观察 |
| --- | --- |
| V0 分析 | 约 132 秒；空间定位修复后五人对应明确，指出 P4 下脸部与发型差异，但未可靠识别嘴角细红色物体。 |
| 人工意见与 V1 | 人工拒绝发型变化，只采纳轻微下颌调整，补充保留眼镜和其他人物、恢复细红色物体等意见；约 259 秒完成合并、生成与复评。实际生成计划包含这些取舍。 |
| V1 人工复核 | 嘴角生成白色短突起，未按要求恢复颜色；脸部形状和质感变化，其他人物口唇/牙齿也被改写。模型复评未给出可靠的细节改善结论，返回不确定项。 |
| V1 再分析 | 尝试原尺寸视觉证据时上游 HTTP 500，约 21 秒结束；不能仅据此认定供应商尺寸上限。改用最长边 3200px 的有界预览后约 81 秒完成，但仍未可靠定位这些小脸细节，允许返回无明确缺陷和身份不确定。 |
| 人工意见与 V2 | 显式以 V1 继续，要求停止瘦脸和美化，修正嘴角白色突起。约 331 秒后停在待人工审阅；图像生成成功，复评上游 HTTP 408，候选保留。 |
| V2 人工复核 | 白色突起仍存在，目标人物相貌进一步漂移，其他人物面部仍有变化。未接受任何候选，会话空闲，可继续查看 V0/V1/V2。 |

另一个先行会话 `890c8b87d3c64444aa38d53c01c87c54` 未生成图片：首次分析因人物定位不足待澄清，随后一次分析失败仅有旧版笼统错误，原因无法追溯；补充安全错误分类后再次分析暴露 schema `value_error`。记录在 `outputs/browser-refinement-real/20260911/`。这些失败推动了原图空间定位、JSON schema 跨字段说明和安全错误分类的修复，未降低契约要求或增加自动文本修复。

## 局部审阅和辅助指标

`face-comparison.png` 按原图、V0、V1、V2 展示同一坐标裁剪；`all-faces-comparison.png` 展示全部五人。原图嘴角的细红色物体被本地换脸抹去；生成虽新增类似物体，颜色和形态仍不符合意见。两轮都保留了五人的大体姿态与场景，面部细节保真不足。

辅助诊断使用现有 SCRFD/ArcFace CPU 模型，以原图 P4 脸框的几何重叠定位候选中的同一位置，再比较单张参考的余弦相似度。原图为 0.135，V0 为 **0.502**，V1 为 **0.285**，V2 为 **0.235**。每版检测到五张脸；歧义几何匹配应返回不可用。这只是单参考外观指标，受姿态、裁剪和生成细节影响，不是身份真值、成片率或自动接受阈值。它与人工观察的相貌漂移一致。
