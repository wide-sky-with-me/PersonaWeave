# NASA 公开组图批量换脸与一致性测试 — 2026-08-16

## 结论

本次正式批处理测试失败，不能作为可交付结果。三张图都生成了候选结果且画布尺寸保持一致，但任务映射被污染，I02 和 I03 的未指定人物被错误换脸；整图重绘还导致文字、徽章和大量非目标像素变化。批次正确停留在 `swapping`，三个作业均为 `needs_review`，没有进入正式验证完成状态。

## 测试设计

- 批次：`39e07773-dc96-4b4a-a5b3-57c001af711b`
- 来源：NASA Image and Video Library 的三张公开成人照片；详细来源、哈希和免责声明见 `data/test_sets/nasa_christina_koch_20260816/manifest.json`。
- 场景覆盖：清晰正脸、戴安全帽与护目镜的侧脸、多人合影。
- 目标：同一个虚构成年女性参考身份 `T01`。
- 原始意图：只把跨三张图的 `P01` 替换为 `T01`，保护所有旁人、发型、眼镜、安全帽、服装、背景、文字和 Logo。
- 生图模型：`doubao-seedream-5-0-pro-260628`。
- 规划与复核模型：`gpt-5.6-sol`。
- 最大循环：每张 2 轮；三张均跑满 2 轮，共产生 6 次付费生图调用。接口未返回账单金额，因此不能给出准确费用。

## 人物分析结果

本地检测找到了三张图中的目标脸，但自动跨图融合只把 I01 和 I02 合并为 `P01`。I03 中同一人物被单列为 `P07`，需要人工根据位置、眼镜、发型、服装和场景确认后合并。系统没有在不确定时自动继续，这一安全行为符合要求；自动融合完整性仍未达标。

## 根因

### 1. 任务映射编译器把保护语句误判成“替换所有人”

用户要求中包含“严格保留其他所有人物”。`compile_instruction_mappings()` 的 `all_people_requested` 正则只要看到“所有人物”就判定为全员处理，没有识别前面的“保留其他”。由于同一句任务中还出现 `@T01`，编译器把每个 `Pxx` 都映射到了 `T01`。数据库中下发给网关的原始 `SwapRequest` 已确认：

- I01：仅 P01 -> T01；
- I02：P01、P02、P03 -> T01；
- I03：P04、P05、P06、P01 -> T01。

因此主要误换发生在模型规划之前，不是 Seedream 自行无视正确映射。

### 2. 模型原生整图编辑破坏非目标内容

即使 I01 只有一个正确映射，结果仍改变了大范围纹理、服装徽章和文字。模型生成的是整张新图，不是受硬蒙版约束的局部身份替换。提示词无法提供像素级授权边界。

### 3. 逐轮评分协议不稳定

- I01 返回 0–10 整数分（9、9、9、9、9、10），但代码按 0–100 阈值解释；摘要却写“通过”。
- I02 返回 0–1 小数分（0.92、0.84 等），Pydantic 需要整数，导致最终复核 `review_unavailable`。
- I03 返回 0–100 分，但目标一致性为 84，低于 85 阈值；摘要仍写“通过”。

当前解析器没有统一评分尺度，也没有拒绝“摘要通过但硬阈值失败”的语义矛盾。停止为 `needs_review` 是安全的，但评价数据本身不稳定。

### 4. 最终跨图 QA 不能弥补上游映射污染

独立 peer 复核把 I01、I03 判为通过，并认为跨图一致；I02 因旁人发型被改判失败。该 QA 把已经污染的结构化映射视为权威，所以会把 I03 的四人换脸当成预期行为。最终 QA 必须同时校验不可变用户原文与结构化映射是否一致，不能只验证生成结果是否服从已编译映射。

## 自然性与一致性判断

- 面部自然性：I01 较好；I02 的目标侧脸基本可用，但旁人误换不可接受；I03 的脸部边缘总体自然。
- 目标身份一致性：三张图呈现了粗粒度相似身份，但角度和小脸尺度下仍存在明显漂移，且误把相同目标扩散到旁人，不能算合格的一致性。
- 原图保持：失败。整图变化比例和可见文字/徽章损坏均远超允许范围。
- 多人安全性：失败。I02 误换 2 人，I03 误换 3 人。
- 批量完整性：需要人工合并才能覆盖三张图；自动分析未独立达标。

## 建议修复顺序

1. 先修复 `all_people_requested` 的否定/保护语境识别，并增加“只替换 P01，保留其他所有人物”的回归测试；执行前比较用户引用集合与最终 replacement 集合，出现扩张就拒绝运行。
2. 统一 reviewer 分数协议：提示中明确 0–100 整数；解析时只接受一个尺度或显式归一化 0–1/0–10，并记录原始尺度；摘要不得覆盖硬阈值。
3. 最终 QA 同时接收不可变用户要求、预期 replacement 集合和实际 compiled mapping，先做映射一致性门禁，再做视觉判断。
4. 正式模式改用面部内部硬蒙版、局部编辑和原图回贴；整图 Seedream 只保留为快速预览。
5. 修复后复用同一组图重跑，但无需再次测试错误映射；先用不付费的映射编译单元测试证明 I02/I03 只有 P01，再进行新的付费生图。
