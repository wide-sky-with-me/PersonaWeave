# 快速开始

启动命令、所需工具、模型下载与可选 AI 配置统一维护在 [README](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/README.md)。先按实际平台选择安装方式，不把 Linux/CUDA 开发锁当作通用 CPU 安装命令。

| 需要 | 阅读入口 |
| --- | --- |
| 源码开发启动与手动运行 | [README：本地启动](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/README.md#本地启动) |
| CPU/ARM64、端口绑定与持久目录 | [Docker 部署](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/docker-deployment.md) |
| Windows 完整包、升级与自检 | [Windows 便携版](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/windows-portable.md) |
| 权重来源、摘要与许可 | [模型说明](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/models/README.md) |
| AI 服务、尺寸策略和费用边界 | [模型目录](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/model-catalog.md)、[运行维护手册](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/operations-runbook.md#ai-配置与调用费用) |
| 素材安装与 manifest 导入 | [素材库](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/portrait-library.md) |

运行后按 [实例登记与启动检查](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/operations-runbook.md#实例登记与启动检查)核对真实入口、健康信息和模型 Provider。实际凭据留在部署环境；健康就绪与真实上游调用验收分别记录。
