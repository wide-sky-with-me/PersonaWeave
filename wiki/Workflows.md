# 工作流

建议按「准备人物 → 本地换脸 → 按需精修 → 保存/导出」阅读。要继续编辑旧结果时，区分只读历史查看与显式工程恢复；完整流程见 [综合交接说明](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/project-handover.md#6-端到端业务流程)。

| 操作 | 权威入口 |
| --- | --- |
| 创建人物、选择参考、归档与导入 | [素材库](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/portrait-library.md) |
| 目标检测、多角色映射与本地换脸 | [本地换脸](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/facefusion-local-swap.md) |
| 批处理、逐图失败与结果回看 | [任务历史](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/task-history.md) |
| 确认诊断、生成整图候选与人工接受 | [精修契约](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/ai-refinement.md)、[工作台](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/refinement-workbench.md) |
| 精修证据、生成和复评边界 | [分析](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/refinement-analysis.md)、[生成](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/refinement-generation.md)、[提示词](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/refinement-prompts.md) |
| 自动保存、刷新和显式恢复工程 | [工程契约](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/studio-projects.md) |
| 下载当前工程的最终图片 | [精修工作台](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/refinement-workbench.md) |
| 历史记录人工质量评价 | [质量档案](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/delivery-quality.md) |

候选图需要人工检查和接受，生成或复评成功不等于自动定稿。远端视觉仲裁与后置图像精修是不同调用；真实请求费用、取消边界和隔离验收方法见 [维护手册](https://github.com/wide-sky-with-me/PersonaWeave/blob/main/docs/operations-runbook.md#ai-配置与调用费用)。
